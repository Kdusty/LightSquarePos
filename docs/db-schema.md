## Tables

### `products`

| Column | Type | Nullable | Notes |
|---|---|---|---|
| `id` | uuid | NO | `DEFAULT gen_random_uuid()`, PK |
| `owner_id` | uuid | NO | FK → `auth.users(id)` ON DELETE CASCADE |
| `name` | text | NO | — |
| `price` | numeric | NO | Menu price in PHP peso |
| `cogs` | numeric | YES | Cost of Goods Sold for base product (Phase 4) |
| `cat` | text | YES | Category string (dynamic, not enum) |
| `stock` | integer | YES | Current stock level |
| `icon` | text | YES | Emoji string for display |
| `image` | text | YES | HTTPS URL (Supabase Storage) or null |
| `variants` | jsonb | YES | Array of variant groups — see JSONB shape below |
| `active` | boolean | YES | Soft-delete flag; `false` = deleted |

**Soft-delete pattern:** `deleteProduct()` sets `active = false`. All queries filter `eq("active", true)`.  
**Realtime channel:** `products-sync`, filtered by `owner_id`.

**`variants` JSONB shape:**
```json
[
  {
    "id": "vg1234",
    "name": "Size",
    "required": true,
    "options": [
      { "id": "vo5678", "name": "Small", "price": 0, "cogs": 0 },
      { "id": "vo9012", "name": "Large", "price": 25, "cogs": 5 }
    ]
  }
]
```
- `required: true` → cashier must select before adding to cart
- `price` → added to base product price
- `cogs` → added to base product COGS (Phase 4 micro-COGS tracking)

### `transactions`

| Column | Type | Nullable | Notes |
|---|---|---|---|
| `id` | uuid | NO | `DEFAULT gen_random_uuid()`, PK |
| `owner_id` | uuid | NO | FK → `auth.users(id)` ON DELETE CASCADE |
| `date` | date | YES | `YYYY-MM-DD` from `todayStr()` |
| `items` | jsonb | YES | Array of cart item objects — see shape below |
| `subtotal` | numeric | YES | Sum of `price × qty` before discounts |
| `discount` | numeric | YES | Discount amount in pesos |
| `tax` | numeric | YES | Extracted VAT (inclusive formula) |
| `total` | numeric | YES | Final amount charged to customer |
| `total_cogs` | numeric | YES | Sum of `cogs × qty` across all items (Phase 4) |
| `net_profit` | numeric | YES | `total - total_cogs` frozen at moment of sale (Phase 4) |
| `method` | text | YES | `Cash` or `GCash` |
| `status` | text | YES | CHECK: `Completed`, `Voided`, `Refunded` |
| `cashier` | text | YES | Staff name at time of sale |

**Realtime channel:** `transactions-sync`, filtered by `owner_id`.

**`items` JSONB shape** (array of cart item objects):
```json
[
  {
    "id": "uuid-of-product",
    "cartKey": "uuid__optionId_optionId",
    "name": "Café Latte",
    "icon": "🥛",
    "price": 145,
    "cogs": 55,
    "qty": 2,
    "note": "No sugar",
    "selectedVariants": [
      { "groupId": "vg1", "groupName": "Size", "optionId": "vo2", "optionName": "Large", "price": 25 }
    ]
  }
]
```

**Tax formula (Philippine BIR inclusive VAT):**
```
vatableSales = total / (1 + taxRate/100)
tax = total - vatableSales
```

## RPC Functions

### `checkout_cart(items jsonb)`

Atomically decrements stock for all cart items. All-or-nothing.

**Input shape:**
```json
[
  { "product_id": "uuid", "qty": 2 },
  { "product_id": "uuid", "qty": 1 }
]
```

**Guards:**
- `qty_needed <= 0` → rejected (prevents negative stock injection exploit)
- Insufficient stock → raises exception `insufficient_stock`
- Acquires row-level lock (`FOR UPDATE`) on each product row

**Returns:** void (raises exception on failure)

## Triggers

### `handle_new_user()`

Fires `AFTER INSERT` on `auth.users`. Creates the new tenant's `store_settings` and `subscriptions` rows with defaults (Trial tier, 14-day expiry from signup).

---

## Functions

### `is_super_admin()`

`SECURITY DEFINER` function. Returns `true` if `auth.uid()` matches the hardcoded platform owner UUID. Used in RLS policies to allow the super-admin to bypass tenant isolation on `subscriptions` SELECT/UPDATE.
